# Recipes app (PWA)

Private Hebrew recipes app: React + Vite + Supabase.

- Dev: `npm run dev` (http://localhost:5173). Unit tests: `npm test`. End-to-end: `npm run e2e`.
- Env vars (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_VAPID_PUBLIC_KEY`) come from `.env.local`.
- Build: `npm run build`; regenerate icons from `public/icon.svg` with `npm run icons`.
