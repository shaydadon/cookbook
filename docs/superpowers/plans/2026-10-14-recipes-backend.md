# Recipes App — Plan 1: Backend (Supabase) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Supabase backend that turns any shared recipe link into a published, AI-rewritten Hebrew recipe with an AI image, reachable from Make.com, the app, and a chat-export importer.

**Architecture:** Postgres (schema, RLS, auth hook, pg_cron) + Deno Edge Functions. Pure logic lives in `supabase/functions/_shared/*.ts` with injected dependencies so it is unit-tested without network; thin function entrypoints wire real clients. A lease-based worker (`claim_next_recipe`) advances each recipe one step at a time.

**Tech Stack:** Supabase CLI (local Docker stack), Postgres 15+ with pg_trgm/pg_cron/pg_net, pgTAP, Deno 2, `npm:@anthropic-ai/sdk@0.133.0`, `npm:zod@4.6.7`, `npm:linkedom@0.18.13`, `npm:@supabase/supabase-js@2.117.3`, `npm:web-push@3.6.7`, OpenAI Images REST API.

**Spec:** `docs/superpowers/specs/2026-10-14-recipes-app-design.md`

**Followed by:** Plan 2 (`docs/superpowers/plans/2026-10-14-recipes-pwa.md`) builds the PWA on top of this backend.

## Global Constraints

- All user-facing strings (errors stored in `recipes.error`, push text, function error messages shown in the app) are Hebrew.
- Text model: `claude-opus-5-5`, `output_config.effort: "medium"`, structured outputs via `output_config.format`, `betas: ["server-side-fallback-2026-07-01"]`, `fallbacks: "default"`. Never forced `tool_choice`, never `thinking: {type: "disabled"}`, never `budget_tokens`.
- Image model: env `OPENAI_IMAGE_MODEL` (default `gpt-image-1`), `size: "1024x1024"`, `output_format: "webp"`.
- Image style suffix (verbatim): `Professional food photography, natural window light, 45-degree angle, neutral linen and wood surface, shallow depth of field, appetizing, no text, no hands.`
- Categories (verbatim, fixed): `ארוחת בוקר`, `מנות עיקריות`, `תוספות`, `סלטים`, `מרקים`, `אפייה וקינוחים`, `לחמים ובצקים`, `משקאות`, `נשנושים`.
- Statuses: `queued`, `rewriting`, `imaging`, `published`, `needs_review`, `failed`. Status = next step to run.
- Retries: `MAX_ATTEMPTS = 3`, backoff 1 min then 5 min; image failure after 3 attempts publishes with `image_path = NULL`.
- `raw_content` capped at 15,000 characters.
- Worker lease 300 s; worker starts no new step after 60 s of wall time.
- All npm/jsr imports go through `supabase/functions/_shared/npm.ts` (single place for version pins).
- Secrets only from env: `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `INGEST_SECRET`, `WORKER_SECRET`, `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, `AI_FAKE` (local only). `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` are injected by Supabase.
- Windows dev machine: commands below are written for Git Bash; Docker Desktop must be running for anything touching the local Supabase stack.

## Review Focus

1. **Same recipe, different URL spellings** (`utm_*`, `www.`/`m.`, trailing slash, `youtu.be` vs `youtube.com/watch`, `/shorts/`) → exactly one recipe; extra shares only. Pinned in Task 4 (normalizer) and Task 10 (ingest integration).
2. **Gateway re-delivers the same message / admin re-imports the same chat export** → no duplicate `shares` rows, no duplicate recipes. Pinned in Task 10.
3. **Real Hebrew WhatsApp exports**: bidi marks (U+200E/U+200F), multi-line messages, system lines without a sender, `14.10.2026` vs `14/10/2026` vs `10/14/26, 9:30 PM`, iOS `[...]` brackets → parsed correctly, system lines ignored. Pinned in Task 11.
4. **Worker dies mid-step** (timeout, crash) → lease expires and the recipe is picked up again; a live lease is never double-claimed. Pinned in Task 9.
5. **A link with no recipe** (Instagram login wall, meme, giant page) → `needs_review` with a Hebrew reason, never an invented recipe, never a crash on a 5 MB page. Pinned in Task 5 (fetch cap/empty) and Task 8 (pipeline).

- [ ] **Step 2: Write the migration** — `supabase/migrations/20261014000001_schema.sql`

```sql
create extension if not exists pg_trgm with schema extensions;

create table public.allowed_emails (
  email         text primary key check (email = lower(email)),
  whatsapp_name text,
  role          text not null default 'member' check (role in ('admin', 'member'))
);

create table public.members (
  id            uuid primary key references auth.users (id) on delete cascade,
  email         text not null,
  display_name  text not null,
  whatsapp_name text,
  role          text not null default 'member' check (role in ('admin', 'member')),
  created_at    timestamptz not null default now()
);

create table public.recipes (
  id                    uuid primary key default gen_random_uuid(),
  status                text not null default 'queued'
                        check (status in ('queued','rewriting','imaging','published','needs_review','failed')),
  source_url            text not null,
  source_url_normalized text not null unique,
  source_platform       text not null check (source_platform in ('web','instagram','tiktok','youtube','facebook')),
  raw_content           text,
  title                 text,
  description           text,
  ingredients           jsonb not null default '[]'::jsonb,
  steps                 jsonb not null default '[]'::jsonb,
  prep_minutes          int,
  cook_minutes          int,
  servings              int,
  category              text check (category is null or category in
                        ('ארוחת בוקר','מנות עיקריות','תוספות','סלטים','מרקים','אפייה וקינוחים','לחמים ובצקים','משקאות','נשנושים')),
  tags                  text[] not null default '{}',
  image_prompt          text,
  image_path            text,
  search_text           text not null default '',
  error                 text,
  attempts              int not null default 0,
  next_attempt_at       timestamptz not null default now(),
  locked_until          timestamptz,
  created_at            timestamptz not null default now(),
  updated_at            timestamptz not null default now(),
  published_at          timestamptz
);

create index recipes_queue_idx     on public.recipes (status, next_attempt_at);
create index recipes_published_idx on public.recipes (published_at desc) where status = 'published';
create index recipes_search_idx    on public.recipes using gin (search_text extensions.gin_trgm_ops);

create function public.recipes_before_write() returns trigger
language plpgsql set search_path = public as $$
begin
  new.search_text := lower(concat_ws(' ',
    new.title, new.description, new.category,
    (select string_agg(i ->> 'name', ' ') from jsonb_array_elements(new.ingredients) as i),
    array_to_string(new.tags, ' ')));
  new.updated_at := now();
  return new;
end $$;

create trigger recipes_before_write
  before insert or update on public.recipes
  for each row execute function public.recipes_before_write();

create table public.shares (
  id             uuid primary key default gen_random_uuid(),
  recipe_id      uuid not null references public.recipes (id) on delete cascade,
  shared_by_name text,
  message_text   text,
  shared_at      timestamptz not null default now(),
  submitted_by   uuid references public.members (id) on delete set null,
  via            text not null check (via in ('whatsapp','app','import')),
  constraint shares_idempotent unique nulls not distinct (recipe_id, shared_by_name, shared_at)
);
create index shares_recipe_idx on public.shares (recipe_id);

create table public.favorites (
  member_id  uuid not null references public.members (id) on delete cascade,
  recipe_id  uuid not null references public.recipes (id) on delete cascade,
  created_at timestamptz not null default now(),
  primary key (member_id, recipe_id)
);

create table public.push_subscriptions (
  id         uuid primary key default gen_random_uuid(),
  member_id  uuid not null references public.members (id) on delete cascade,
  endpoint   text not null unique,
  p256dh     text not null,
  auth       text not null,
  created_at timestamptz not null default now()
);

-- Feed + search + favorites filter in one call. SECURITY INVOKER: RLS still applies.
create function public.search_recipes(
  q text default null, cat text default null, favorites_only boolean default false,
  page_size int default 24, page_offset int default 0)
returns setof public.recipes
language sql stable set search_path = public as $$
  select r.* from public.recipes r
  where r.status = 'published'
    and (coalesce(q, '') = ''
         or r.search_text like '%' || replace(replace(replace(lower(q), '\', '\\'), '%', '\%'), '_', '\_') || '%')
    and (cat is null or r.category = cat)
    and (not favorites_only or exists (
         select 1 from public.favorites f where f.recipe_id = r.id and f.member_id = auth.uid()))
  order by r.published_at desc nulls last
  limit least(page_size, 100) offset greatest(page_offset, 0);
$$;
```

- [ ] **Step 3: Write the migration** — `supabase/migrations/20261014000002_auth_rls.sql`

```sql
-- Role helpers (security definer so policies can call them without recursive RLS)
create function public.is_member() returns boolean
language sql stable security definer set search_path = public as $$
  select exists (select 1 from public.members where id = auth.uid());
$$;

create function public.is_admin() returns boolean
language sql stable security definer set search_path = public as $$
  select exists (select 1 from public.members where id = auth.uid() and role = 'admin');
$$;

-- Auth hook: only allow-listed emails may sign up
create function public.hook_before_user_created(event jsonb) returns jsonb
language plpgsql stable security definer set search_path = public as $$
begin
  if exists (select 1 from public.allowed_emails where email = lower(event -> 'user' ->> 'email')) then
    return '{}'::jsonb;
  end if;
  return jsonb_build_object('error', jsonb_build_object(
```

```ts
import type { Platform } from "./types.ts";

export const BROWSER_HEADERS: Record<string, string> = {
  "User-Agent":
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/131.0 Safari/537.36",
  "Accept-Language": "he-IL,he;q=0.9,en;q=0.8",
  "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
};

const URL_RE = /https?:\/\/[^\s<>"'“”]+/gi;
const TRAILING_PUNCT_RE = /[.,!?;:)\]}»״׳'"]+$/u;

const TRACKING_PARAMS = [
  /^utm_/, /^fbclid$/, /^gclid$/, /^igshid$/, /^igsh$/, /^si$/, /^ref$/, /^ref_src$/,
  /^mibextid$/, /^share_id$/, /^_r$/, /^_t$/, /^feature$/, /^is_from_webapp$/, /^sender_device$/,
];

const SHORT_HOSTS = new Set([
  "bit.ly", "tinyurl.com", "t.co", "goo.gl", "vm.tiktok.com", "vt.tiktok.com", "fb.watch", "s.id", "rb.gy",
]);

export function extractUrls(text: string): string[] {
  const found = (text.match(URL_RE) ?? []).map((u) => u.replace(TRAILING_PUNCT_RE, ""));
  return [...new Set(found)];
}

function bareHost(hostname: string): string {
  return hostname.toLowerCase().replace(/^(www|m|mobile)\./, "");
}

export function normalizeUrl(raw: string): string {
  const u = new URL(raw.trim()); // throws TypeError on garbage
  const host = bareHost(u.hostname);

  for (const key of [...new Set(u.searchParams.keys())]) {
    if (TRACKING_PARAMS.some((re) => re.test(key))) u.searchParams.delete(key);
  }
  u.searchParams.sort();

  if (host === "youtu.be") return `https://youtube.com/watch?v=${u.pathname.slice(1).replace(/\/+$/, "")}`;
  if (host === "youtube.com") {
    const shorts = u.pathname.match(/^\/shorts\/([^/]+)/);
    const id = shorts?.[1] ?? u.searchParams.get("v");
    if (id) return `https://youtube.com/watch?v=${id}`;
  }

  const path = u.pathname.replace(/\/+$/, "");
  const qs = u.searchParams.toString();
  const port = u.port ? `:${u.port}` : "";
  return `https://${host}${port}${path}${qs ? `?${qs}` : ""}`;
}

export function detectPlatform(url: string): Platform {
  const host = bareHost(new URL(url).hostname);
  if (host.endsWith("instagram.com")) return "instagram";
  if (host.endsWith("tiktok.com")) return "tiktok";
  if (host === "youtu.be" || host.endsWith("youtube.com")) return "youtube";
  if (host.endsWith("facebook.com") || host === "fb.watch") return "facebook";
  return "web";
}

export async function resolveUrl(url: string, fetchFn: typeof fetch = fetch): Promise<string> {
  if (!SHORT_HOSTS.has(bareHost(new URL(url).hostname))) return url;
  try {
    const res = await fetchFn(url, { redirect: "follow", headers: BROWSER_HEADERS });
    await res.body?.cancel();
    return res.url || url;
  } catch {
    return url;
  }
}
```

```ts
import { parseHTML } from "./npm.ts";

export interface Extracted {
  jsonLdRecipe: Record<string, unknown> | null;
  title: string | null;
  description: string | null;
  text: string;
}

export function findRecipe(node: unknown): Record<string, unknown> | null {
  if (Array.isArray(node)) {
    for (const n of node) {
      const r = findRecipe(n);
      if (r) return r;
    }
    return null;
  }
  if (node && typeof node === "object") {
    const obj = node as Record<string, unknown>;
    const t = obj["@type"];
    const types = Array.isArray(t) ? t : [t];
    if (types.includes("Recipe")) return obj;
    if (obj["@graph"]) return findRecipe(obj["@graph"]);
  }
  return null;
}

export function extractFromHtml(html: string): Extracted {
  const { document } = parseHTML(html);

  let jsonLdRecipe: Record<string, unknown> | null = null;
  for (const s of document.querySelectorAll('script[type="application/ld+json"]')) {
    try {
      jsonLdRecipe = findRecipe(JSON.parse(s.textContent ?? ""));
    } catch {
      // malformed JSON-LD is common; skip it
    }
    if (jsonLdRecipe) break;
  }

  const meta = (selector: string): string | null =>
    document.querySelector(selector)?.getAttribute("content")?.trim() || null;
  const title = meta('meta[property="og:title"]') ?? (document.querySelector("title")?.textContent?.trim() || null);
  const description = meta('meta[property="og:description"]') ?? meta('meta[name="description"]');

  for (const el of document.querySelectorAll("script,style,noscript,nav,header,footer,aside,form,iframe,svg")) {
    el.remove();
  }
  const root = document.querySelector("article") ?? document.querySelector("main") ?? document.body;
  const text = (root?.textContent ?? "").replace(/\s+/g, " ").trim();

  return { jsonLdRecipe, title, description, text };
}
```

```ts
import { extractFromHtml } from "./extract.ts";
import type { Platform } from "./types.ts";
import { BROWSER_HEADERS } from "./url.ts";

export const MAX_RAW_CONTENT = 15000;
export const MAX_HTML_BYTES = 2_000_000;
const MIN_USEFUL_CHARS = 40;

export interface SourceInput {
  url: string;
  platform: Platform;
  messageText: string | null;
}

const OEMBED: Partial<Record<Platform, string>> = {
  tiktok: "https://www.tiktok.com/oembed?url=",
  youtube: "https://www.youtube.com/oembed?format=json&url=",
};

export async function fetchSource(input: SourceInput, fetchFn: typeof fetch = fetch): Promise<string | null> {
  const parts: string[] = [];
  let networkError: Error | null = null;

  const oembed = OEMBED[input.platform];
  if (oembed) {
    try {
      const res = await fetchFn(oembed + encodeURIComponent(input.url));
      if (res.ok) {
        const j = await res.json();
        if (j.title) parts.push(`כיתוב הפוסט: ${j.title}`);
        if (j.author_name) parts.push(`יוצר: ${j.author_name}`);
      } else {
        await res.body?.cancel();
      }
    } catch (e) {
      networkError = e as Error;
    }
  }

  try {
    const res = await fetchFn(input.url, { headers: BROWSER_HEADERS, redirect: "follow" });
    if (res.ok && (res.headers.get("content-type") ?? "").includes("html")) {
      const html = (await res.text()).slice(0, MAX_HTML_BYTES);
      const ex = extractFromHtml(html);
      if (ex.jsonLdRecipe) {
        parts.push(`נתוני מתכון מובנים (JSON-LD):\n${JSON.stringify(ex.jsonLdRecipe)}`);
      } else if (input.platform === "web") {
        if (ex.title) parts.push(`כותרת: ${ex.title}`);
        if (ex.description) parts.push(`תיאור: ${ex.description}`);
        if (ex.text) parts.push(`תוכן העמוד:\n${ex.text}`);
      } else if (ex.description) {
        // social pages: the caption lives in og:description; the body is login-wall noise
        parts.push(`כיתוב הפוסט: ${ex.description}`);
      }
    } else {
      await res.body?.cancel();
    }
  } catch (e) {
    networkError = e as Error;
  }

  const fromSource = parts.join("\n\n").trim();
  const message = input.messageText?.trim() ?? "";

  if (fromSource.length < MIN_USEFUL_CHARS && message.length < MIN_USEFUL_CHARS) {
    if (networkError) throw networkError;
    return null;
  }

  const combined = [fromSource, message && `הודעת הוואטסאפ ששותפה עם הקישור:\n${message}`]
    .filter(Boolean)
    .join("\n\n");
  return combined.slice(0, MAX_RAW_CONTENT);
}
```

```ts
export async function rewriteRecipe(raw: string, client: Anthropic): Promise<RewriteResult> {
  const params = {
    model: REWRITE_MODEL,
    max_tokens: 16000,
    betas: ["server-side-fallback-2026-07-01"],
    fallbacks: "default",
    output_config: {
      effort: "medium",
      format: { type: "json_schema", schema: RECIPE_JSON_SCHEMA },
    },
    system: SYSTEM_PROMPT,
    messages: [{ role: "user", content: `<source>\n${raw}\n</source>` }],
  };
  const response = await client.beta.messages.create(
    params as unknown as Parameters<typeof client.beta.messages.create>[0],
  ) as unknown as {
    stop_reason: string;
    stop_details?: { category?: string | null } | null;
    content: { type: string; text?: string }[];
  };

  if (response.stop_reason === "refusal") {
    throw new Error(`Claude declined the request (${response.stop_details?.category ?? "unknown"})`);
  }
  if (response.stop_reason === "max_tokens") throw new Error("Claude output truncated (max_tokens)");

  const text = response.content.filter((b) => b.type === "text").map((b) => b.text ?? "").join("");
  const recipe = RecipeAiSchema.parse(JSON.parse(text));

  if (recipe.insufficient_content || recipe.ingredients.length === 0 || recipe.steps.length === 0) {
    return { kind: "insufficient" };
  }
  return { kind: "ok", recipe };
}
```

```ts
import { decodeBase64 } from "./npm.ts";

export const IMAGE_STYLE =
  "Professional food photography, natural window light, 45-degree angle, neutral linen and wood surface, shallow depth of field, appetizing, no text, no hands.";

export async function generateImage(
  prompt: string,
  opts: { apiKey: string; model: string; fetchFn?: typeof fetch },
): Promise<Uint8Array> {
  const fetchFn = opts.fetchFn ?? fetch;
  const res = await fetchFn("https://api.openai.com/v1/images/generations", {
    method: "POST",
    headers: { Authorization: `Bearer ${opts.apiKey}`, "Content-Type": "application/json" },
    body: JSON.stringify({
      model: opts.model,
      prompt: `${prompt}. ${IMAGE_STYLE}`,
      size: "1024x1024",
      quality: "medium",
      output_format: "webp",
      n: 1,
    }),
  });
  if (!res.ok) throw new Error(`OpenAI image ${res.status}: ${(await res.text()).slice(0, 300)}`);
  const json = await res.json();
  const b64 = json?.data?.[0]?.b64_json;
  if (typeof b64 !== "string") throw new Error("OpenAI image: response had no image data");
  return decodeBase64(b64);
}
```

```ts
import { webpush } from "./npm.ts";

export interface PushSubscriptionRow { id: string; endpoint: string; p256dh: string; auth: string }
export interface PushPayload { title: string; body: string; url: string }
export type SendFn = (sub: PushSubscriptionRow, body: string) => Promise<void>;

export async function sendPushToAll(
  subs: PushSubscriptionRow[],
  payload: PushPayload,
  send: SendFn,
): Promise<string[]> {
  const body = JSON.stringify(payload);
  const dead: string[] = [];
  await Promise.all(subs.map(async (s) => {
    try {
      await send(s, body);
    } catch (e) {
      const code = (e as { statusCode?: number }).statusCode;
      if (code === 404 || code === 410) dead.push(s.id);
      else console.error("push failed", s.id, code ?? e);
    }
  }));
  return dead;
}

export function webPushSender(vapid: { publicKey: string; privateKey: string; subject: string }): SendFn {
  webpush.setVapidDetails(vapid.subject, vapid.publicKey, vapid.privateKey);
  return async (s, body) => {
    await webpush.sendNotification({ endpoint: s.endpoint, keys: { p256dh: s.p256dh, auth: s.auth } }, body, { TTL: 86400 });
  };
}
```

```ts
export const BACKOFF_MINUTES = [1, 5];

export interface PipelineDeps {
  fetchSource(input: SourceInput): Promise<string | null>;
  loadMessageText(recipeId: string): Promise<string | null>;
  rewrite(raw: string): Promise<RewriteResult>;
  generateImage(prompt: string): Promise<Uint8Array>;
  uploadImage(recipeId: string, bytes: Uint8Array): Promise<string>;
  now(): Date;
}

const RUNNABLE = new Set(["queued", "rewriting", "imaging"]);

const orNull = (s: string) => (s.trim() === "" ? null : s.trim());
const positiveOrNull = (n: number) => (n > 0 ? n : null);

export function normalizeTags(tags: string[]): string[] {
  return [...new Set(tags.map((t) => t.trim()).filter(Boolean))].slice(0, 5);
}

export function resumeStatus(r: Pick<RecipeRow, "raw_content" | "title">): "queued" | "rewriting" | "imaging" {
  if (!r.raw_content) return "queued";
  if (!r.title) return "rewriting";
  return "imaging";
}

async function runStep(r: RecipeRow, deps: PipelineDeps): Promise<RecipePatch> {
  switch (r.status) {
    case "queued": {
      const raw = r.raw_content ??
        await deps.fetchSource({ url: r.source_url, platform: r.source_platform, messageText: await deps.loadMessageText(r.id) });
      if (!raw) return { status: "needs_review", error: "לא נמצא תוכן מתכון בקישור", attempts: 0 };
      return { status: "rewriting", raw_content: raw, attempts: 0, error: null };
    }
    case "rewriting": {
      const res = await deps.rewrite(r.raw_content ?? "");
      if (res.kind === "insufficient") {
        return { status: "needs_review", error: "לא נמצא מתכון מלא בתוכן (חסרים מרכיבים או אופן הכנה)", attempts: 0 };
      }
      const x = res.recipe;
      return {
        status: "imaging",
        title: x.title.trim(),
        description: orNull(x.description),
        ingredients: x.ingredients.map((i) => ({
          group: orNull(i.group), name: i.name.trim(), amount: orNull(i.amount), unit: orNull(i.unit), note: orNull(i.note),
        })),
        steps: x.steps.map((s) => ({ text: s.text.trim() })).filter((s) => s.text),
        prep_minutes: positiveOrNull(x.prep_minutes),
        cook_minutes: positiveOrNull(x.cook_minutes),
        servings: positiveOrNull(x.servings),
        category: x.category,
        tags: normalizeTags(x.tags),
        image_prompt: x.image_prompt.trim() || x.title,
        attempts: 0,
        error: null,
      };
    }
    case "imaging": {
      const bytes = await deps.generateImage(r.image_prompt ?? r.title ?? "");
      const path = await deps.uploadImage(r.id, bytes);
      return { status: "published", image_path: path, published_at: deps.now().toISOString(), attempts: 0, error: null };
    }
    default:
      throw new Error(`advanceRecipe: status ${r.status} is not runnable`);
  }
}

export async function advanceRecipe(r: RecipeRow, deps: PipelineDeps): Promise<RecipePatch> {
  if (!RUNNABLE.has(r.status)) throw new Error(`advanceRecipe: status ${r.status} is not runnable`);
  try {
    return await runStep(r, deps);
  } catch (err) {
    const msg = err instanceof Error ? err.message : String(err);
    const attempts = r.attempts + 1;
    if (attempts < MAX_ATTEMPTS) {
      const delayMs = BACKOFF_MINUTES[attempts - 1] * 60_000;
      return { attempts, error: msg, next_attempt_at: new Date(deps.now().getTime() + delayMs).toISOString() };
    }
    if (r.status === "imaging") {
      return {
        status: "published", image_path: null, published_at: deps.now().toISOString(),
        attempts, error: `יצירת התמונה נכשלה: ${msg}`,
      };
    }
    return { status: "failed", attempts, error: msg };
  }
}
```

```sql
create function public.claim_next_recipe(lease_seconds int default 300)
returns setof public.recipes
language sql security definer set search_path = public as $$
  update public.recipes
  set locked_until = now() + make_interval(secs => lease_seconds)
  where id = (
    select id from public.recipes
    where status in ('queued', 'rewriting', 'imaging')
      and next_attempt_at <= now()
      and (locked_until is null or locked_until < now())
    order by next_attempt_at
    for update skip locked
    limit 1)
  returning *;
$$;
```

```ts
export function background(p: Promise<unknown>): void {
  const rt = (globalThis as { EdgeRuntime?: { waitUntil(p: Promise<unknown>): void } }).EdgeRuntime;
```

```ts
import type { SupabaseClient } from "./npm.ts";
import { advanceRecipe, type PipelineDeps } from "./pipeline.ts";
import { type PushSubscriptionRow, type SendFn, sendPushToAll } from "./push.ts";
import type { RecipePatch, RecipeRow } from "./types.ts";

const START_NO_NEW_STEP_AFTER_MS = 60_000;

export async function notifyPublished(db: SupabaseClient, send: SendFn | null, recipe: { id: string; title: string }) {
  if (!send) return;
  const { data: subs, error } = await db.from("push_subscriptions").select("id, endpoint, p256dh, auth");
  if (error || !subs?.length) return;
  const dead = await sendPushToAll(subs as PushSubscriptionRow[], {
    title: "מתכון חדש באפליקציה 🍳",
    body: recipe.title,
    url: `/recipe/${recipe.id}`,
  }, send);
  if (dead.length) await db.from("push_subscriptions").delete().in("id", dead);
}

export async function runOne(
  db: SupabaseClient,
  deps: PipelineDeps & { sendPush: SendFn | null },
  recipe: RecipeRow,
): Promise<RecipePatch> {
  const patch = await advanceRecipe(recipe, deps);
  const { error } = await db.from("recipes").update({ ...patch, locked_until: null }).eq("id", recipe.id);
  if (error) throw new Error(`update recipe ${recipe.id}: ${error.message}`);
  if (patch.status === "published") {
    await notifyPublished(db, deps.sendPush, { id: recipe.id, title: patch.title ?? recipe.title ?? "" });
  }
  return patch;
}

export async function runWorker(
  db: SupabaseClient,
  deps: PipelineDeps & { sendPush: SendFn | null },
  budgetMs = START_NO_NEW_STEP_AFTER_MS,
): Promise<number> {
  const started = Date.now();
  let steps = 0;
  while (Date.now() - started < budgetMs) {
    const { data, error } = await db.rpc("claim_next_recipe", { lease_seconds: 300 });
    if (error) throw new Error(`claim: ${error.message}`);
    const recipe = (data as RecipeRow[] | null)?.[0];
    if (!recipe) break;
    await runOne(db, deps, recipe);
    steps++;
  }
  return steps;
}

export async function kickWorker(): Promise<void> {
  await fetch(`${Deno.env.get("SUPABASE_URL")}/functions/v1/process-recipe`, {
    method: "POST",
    headers: { Authorization: `Bearer ${Deno.env.get("WORKER_SECRET")}`, "Content-Type": "application/json" },
    body: "{}",
  }).then((r) => r.body?.cancel());
}
```

```ts
import type { SupabaseClient } from "./npm.ts";
import { detectPlatform, extractUrls, normalizeUrl, resolveUrl } from "./url.ts";

export interface IngestInput {
  text: string;
  senderName: string | null;
  sentAt: string | null;
  via: "whatsapp" | "app" | "import";
  submittedBy: string | null;
}

export interface IngestResult { url: string; recipe_id: string; status: string; duplicate: boolean }

export async function ingest(
  db: SupabaseClient,
  input: IngestInput,
  resolve: (u: string) => Promise<string> = (u) => resolveUrl(u),
): Promise<IngestResult[]> {
  const results: IngestResult[] = [];
  const sharedAt = input.sentAt ?? new Date().toISOString();

  for (const raw of extractUrls(input.text)) {
    let normalized: string;
    try {
      normalized = normalizeUrl(await resolve(raw));
    } catch {
      continue; // not a valid URL
    }

    let recipe = (await db.from("recipes").select("id, status").eq("source_url_normalized", normalized).maybeSingle()).data;
    let duplicate = recipe !== null;
    if (!recipe) {
      const inserted = await db.from("recipes")
        .insert({ source_url: raw, source_url_normalized: normalized, source_platform: detectPlatform(normalized) })
        .select("id, status").single();
      if (inserted.error?.code === "23505") {
        recipe = (await db.from("recipes").select("id, status").eq("source_url_normalized", normalized).single()).data;
        duplicate = true;
      } else if (inserted.error) {
        throw new Error(`insert recipe: ${inserted.error.message}`);
      } else {
        recipe = inserted.data;
      }
    }

    const share = await db.from("shares").upsert({
      recipe_id: recipe!.id,
      shared_by_name: input.senderName,
      message_text: input.text,
      shared_at: sharedAt,
      via: input.via,
      submitted_by: input.submittedBy,
    }, { onConflict: "recipe_id,shared_by_name,shared_at", ignoreDuplicates: true });
    if (share.error) throw new Error(`insert share: ${share.error.message}`);

    results.push({ url: raw, recipe_id: recipe!.id, status: recipe!.status, duplicate });
  }
  return results;
}
```

```ts
export interface ChatMessage { sender: string; sentAt: string; text: string }

const BIDI = /[‎‏‪-‮⁦-⁩]/g;
// [date, time(, AM/PM)] or date, time(, AM/PM) - ; then "sender: text" (sender optional = system line)
const HEADER_RE =
  /^\[?(\d{1,2})[./](\d{1,2})[./](\d{2,4}),?\s+(\d{1,2}):(\d{2})(?::(\d{2}))?\s*([AaPp][Mm])?\]?\s*(?:-\s*)?(.*)$/;
const SENDER_RE = /^([^:]{1,60}):\s?([\s\S]*)$/;

function tzOffsetMinutes(utcMs: number): number {
  const parts = new Intl.DateTimeFormat("en-US", {
    timeZone: "Asia/Jerusalem", hourCycle: "h23",
    year: "numeric", month: "2-digit", day: "2-digit", hour: "2-digit", minute: "2-digit", second: "2-digit",
  }).formatToParts(new Date(utcMs));
  const get = (t: string) => Number(parts.find((p) => p.type === t)!.value);
  const asUtc = Date.UTC(get("year"), get("month") - 1, get("day"), get("hour"), get("minute"), get("second"));
  return (asUtc - utcMs) / 60_000;
}

export function jerusalemToIso(y: number, mo: number, d: number, h: number, mi: number, s: number): string {
  const guess = Date.UTC(y, mo - 1, d, h, mi, s);
  const offset = tzOffsetMinutes(guess - tzOffsetMinutes(guess) * 60_000);
  return new Date(guess - offset * 60_000).toISOString();
}

function parseHeader(line: string): { sentAt: string; rest: string } | null {
  const m = line.match(HEADER_RE);
  if (!m) return null;
  let [a, b, year] = [Number(m[1]), Number(m[2]), Number(m[3])];
  const ampm = m[7]?.toUpperCase();
  // Day-first (Israel) unless the second number can only be a day, or the export is US-style (AM/PM)
  let day = a, month = b;
  if (b > 12 || (ampm && a <= 12)) [day, month] = [b, a];
  if (month > 12 || day > 31) return null;
  if (year < 100) year += 2000;
  let hour = Number(m[4]);
  if (ampm === "PM" && hour < 12) hour += 12;
  if (ampm === "AM" && hour === 12) hour = 0;
  return { sentAt: jerusalemToIso(year, month, day, hour, Number(m[5]), Number(m[6] ?? 0)), rest: m[8] };
}

export function parseChatExport(content: string): ChatMessage[] {
  const messages: ChatMessage[] = [];
  let current: ChatMessage | null = null;
  let inSystem = false;

  for (const rawLine of content.split(/\r?\n/)) {
    const line = rawLine.replace(BIDI, "");
    const header = parseHeader(line);
    if (header) {
      const sm = header.rest.match(SENDER_RE);
      if (sm) {
        current = { sender: sm[1].trim(), sentAt: header.sentAt, text: sm[2] };
        messages.push(current);
        inSystem = false;
      } else {
        current = null;
        inSystem = true; // system line ("messages are end-to-end encrypted", "X added Y")
      }
    } else if (current && !inSystem) {
      current.text += `\n${line}`;
    }
  }
  return messages.map((m) => ({ ...m, text: m.text.trim() }));
}
```

```ts
const TIME_BUDGET_MS = 90_000;

Deno.serve(async (req) => {

  const started = Date.now();
  let i = offset, created = 0, duplicates = 0;
```

````markdown
# Setup

## 1. Supabase project
1. Create a project at https://supabase.com (region: closest to Israel, e.g. `eu-central-1`).
2. `npx supabase login` then `npx supabase link --project-ref <ref>`.
3. `npx supabase db push` (applies all migrations).
4. Authentication → Hooks → enable **Before User Created** → Postgres function `public.hook_before_user_created`.
5. Authentication → URL configuration: Site URL = your Vercel URL; add it to Redirect URLs.
6. Authentication → Providers → Google: create an OAuth client in Google Cloud Console (Web), paste client id/secret, add the Supabase callback URL shown there to Google's authorised redirect URIs.
7. SQL editor — seed yourself as admin and add the Vault secrets for the cron job:
   ```sql
   insert into public.allowed_emails (email, whatsapp_name, role) values ('shaydadon@gmail.com', 'שי', 'admin');
   select vault.create_secret('https://<ref>.supabase.co', 'project_url');
   select vault.create_secret('<same value as WORKER_SECRET>', 'worker_secret');
   ```

## 2. Function secrets
Generate VAPID keys once: `npx web-push generate-vapid-keys`.
```bash
npx supabase secrets set ANTHROPIC_API_KEY=... OPENAI_API_KEY=... OPENAI_IMAGE_MODEL=gpt-image-1 \
  INGEST_SECRET=$(openssl rand -hex 24) WORKER_SECRET=<same as vault worker_secret> \
  VAPID_PUBLIC_KEY=... VAPID_PRIVATE_KEY=... VAPID_SUBJECT=mailto:shaydadon@gmail.com
npx supabase functions deploy
```
Never set `AI_FAKE` in production.

## 3. WhatsApp gateway (Green API)
1. Buy/assign a dedicated SIM; install WhatsApp on a spare phone with it.
2. Create a Green API instance; scan its QR code from that phone (Linked devices).
3. Add the number to the recipes group.
4. In the instance settings enable **incoming message webhooks** and set the webhook URL to the Make webhook from step 4.

## 4. Make scenario
1. Trigger: **Webhooks → Custom webhook** (copy its URL into Green API).
2. Filter: `messageData.textMessageData.textMessage` *or* `messageData.extendedTextMessageData.text` contains `http`, **and** `senderData.chatId` equals the group id (ends with `@g.us`).
3. Action: **HTTP → Make a request**
   - URL: `https://<ref>.supabase.co/functions/v1/ingest`
   - Method: POST, Body type: Raw, Content type: JSON
   - Headers: `x-ingest-secret: <INGEST_SECRET>`
   - Body:
     ```json
     {"text": "{{coalesce(messageData.extendedTextMessageData.text; messageData.textMessageData.textMessage)}}",
      "sender_name": "{{senderData.senderName}}",
      "sent_at": "{{formatDate(parseDate(timestamp; \"X\"); \"YYYY-MM-DDTHH:mm:ssZ\")}}"}
     ```
4. Turn the scenario on. Post a link in the group and watch `recipes` in the Table Editor.

## 5. Importing history
````

- [ ] **Step 2: Write `.github/workflows/deploy-backend.yml`**

```yaml
name: Deploy backend

on:
  push:
    branches: [main]
    paths: ["supabase/**", ".github/workflows/deploy-backend.yml"]
  workflow_dispatch:

concurrency:
  group: deploy-backend
  cancel-in-progress: false

permissions:
  contents: read

jobs:
  test:
    runs-on: ubuntu-latest
    timeout-minutes: 20
    steps:
      - uses: actions/checkout@v4
      - uses: denoland/setup-deno@v2
        with:
          deno-version: v2.x
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: npm ci
      - run: npm run test:unit
      - run: npx supabase start
      - run: npm run test:db
      - run: npm run test:integration -- --filter "/worker|variants|delivered|two links/"

  deploy:
    needs: test
    runs-on: ubuntu-latest
    env:
      SUPABASE_ACCESS_TOKEN: ${{ secrets.SUPABASE_ACCESS_TOKEN }}
      SUPABASE_DB_PASSWORD: ${{ secrets.SUPABASE_DB_PASSWORD }}
      PROJECT_REF: ${{ secrets.SUPABASE_PROJECT_REF }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: npm ci
      - name: Skip when secrets are missing
        id: guard
        run: |
          if [ -z "$SUPABASE_ACCESS_TOKEN" ] || [ -z "$PROJECT_REF" ]; then
            echo "::warning::Supabase secrets not set; skipping deploy"; echo "skip=true" >> "$GITHUB_OUTPUT"
          fi
      - if: steps.guard.outputs.skip != 'true'
        run: npx supabase link --project-ref "$PROJECT_REF"
      - if: steps.guard.outputs.skip != 'true'
        run: npx supabase db push
      - if: steps.guard.outputs.skip != 'true'
        run: npx supabase functions deploy --project-ref "$PROJECT_REF"
```

(The integration filter skips the admin/push test, which needs `functions serve` running.)
